How to use

AQUATOX Calibration Tool allows you to configure, simulate and calibrate your AQUATOX scenarios. Here is a quick notice on How to use it.

1 — Setup
Set the path to AQUATOX.exe and a working directory where temporary files and results will be saved. These paths are remembered as long as the app is open.
2 — Open a configuration file
Click Open .txt to load an AQUATOX scenario file. The tool will parse it automatically and display all detected species and their calibratable parameters.
3 — Edit parameters
For each species, you can adjust the Value and Tolerance (%) of each parameter. Check the box next to a parameter to include it in calibration. You can use Check All / Uncheck All to select quickly.
4 — Run Simulation
Launches a single AQUATOX run using the current parameter values. A report comparing initial vs final biomasses will appear automatically it allow to check the error for each species.
5 — Calibration
Calibrate optimises only the checked parameters using Nelder-Mead. Auto groups parameters into blocks and calibrates them sequentially. Set Max iterations and Block size to control the process.
6 — Sensitivity Analysis
Varies each checked parameter one at a time over its tolerance range and measures the impact on simulated biomass. Results are saved as graphs in the output folder.
7 — Results
Plot Results generates comparison graphs for all species. Open Folder opens the output directory directly in Explorer.
8 — Save Excel
Exports the current parameter configuration to a .xlsx file for archiving or sharing with colleagues.
